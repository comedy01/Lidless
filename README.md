# Lidless

See inside chests, barrels and shulker boxes just by looking at them. Also adds search and sorting to storage screens and shulker box previews in tooltips. Client-side, works on any server.



## Building

`./gradlew build -Pminecraft_version=26.3` builds the Fabric jar for one version; add `-Ploader=neoforge` for NeoForge. `./gradlew runClientGameTest -Pminecraft_version=26.3` runs the in-game test on Fabric.
